# telegram-chat-control

Кроссплатформенный скилл Codex для работы с Telegram через локальный SQLite-индекс и Telethon.

Скилл хранит Telegram-сессии и локальные данные чатов вне репозитория. Системный keyring используется в первую очередь, с защищённым локальным fallback при его отсутствии. Никогда не добавляйте в GitHub ключи, сессии, базы данных, выгрузки переписок или медиафайлы.

Полная инструкция по установке и использованию находится в [`SKILL.md`](SKILL.md).
