# Local data model

Каждый аккаунт имеет отдельную SQLite-базу в каталоге данных скилла. Миграции добавляют поля без удаления существующих переписок, комментариев или allowlist.

- `peers` — чат и его метаданные: тип, visibility, unread/archive/mute/pin, темы, размер и роль.
- `entities` — отправители и другие Telegram-сущности; эта таблица предотвращает подмену отправителя названием чата.
- `messages` — текст, направление, ответ, тема, медиа, реакции, пересылка, редактирование и удаление.
- `messages_fts` — полнотекстовый индекс исходного текста и расшифровок голосовых.

Удаление не удаляет строку и её FTS-запись. Вместо этого выставляются `is_deleted`, `deleted_at` и `deletion_source` (`event` или `audit`). Если Telegram присылает удаление без ID чата, сообщение помечается только при единственном локальном совпадении; иначе событие сохраняется для последующей сверки.
